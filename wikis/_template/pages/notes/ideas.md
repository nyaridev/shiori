## How an idea becomes a plan

:::steps
1. Write it down: One line in the table above, however rough.
2. Talk it through: When it comes up twice, give it its own page and an `idea` status.
3. Decide: Compare it with what's already planned, and log the call in the [[Decision log]].
4. Plan it: Add it to the [[Roadmap]] with a milestone.
:::
