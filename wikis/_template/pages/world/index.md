:::private[An example to replace]
This `world/` section shows what a public wiki is: the pages `wiki.json`'s `public` block shares with players, with
no comments, questions or notes from the team. This page is its front page (`public.front`). Preview it from
**Share → Public wiki**, or run `pnpm shiori export {{id}}` for a .zip. Keep it as a pattern for your game's pages,
or delete the `world/` folder and the `public` block. Private blocks like this one never reach players.
